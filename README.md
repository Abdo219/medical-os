# Medical OS

Open `index.html` through a local web server for development. For PWA installation and reliable service-worker/offline behavior, host this folder on HTTPS (or localhost).

Android: open the site in Chrome, then menu → **Install app** or **Add to Home screen**.

iPhone: open it in Safari, tap Share → **Add to Home Screen**.

All records are stored locally in IndexedDB. Use **Export Full Backup** regularly; backup import supports `Replace` and `Merge`.
